# ZubApp

Прототип мобильного приложения для стоматологий: React Native, Expo, TypeScript.
Android и iOS. Интерфейс сценария учредителя адаптирован по предоставленным PNG-макетам.

## Реализованный сценарий

Мои клиники → главная клиники → анализ конкурентов → рейтинг → карточка компании.
Можно переключать клиники, фильтровать конкурентов по радиусу, сортировать по расстоянию
или выручке, просматривать место в рейтинге, динамику и реквизиты компании.
Возврат работает через кнопку в заголовке и системную кнопку Android.
Профиль содержит информацию о прототипе.

Все компании и показатели вымышлены. Расстояния иллюстративные, без геокодирования.
Рейтинг охватывает только демонстрационную выборку. Выручка показана за 2025 год.
График за 2023–2025 построен из демонстрационной выручки и темпа роста.
Авторизация, сервер, расписание врача и операционная панель директора ещё не реализованы.

## Разработка

```bash
npm ci
npm start
```

Для телефона нужна совместимая с Expo SDK версия Expo Go либо development build.
Телефон должен иметь доступ к Metro. Облачная среда сама по себе не обеспечивает
подключение телефона. Android-эмулятор требует Android SDK, iOS-симулятор — macOS и Xcode.

## Проверки

```bash
npm run typecheck
npm test
npx expo export --platform android --platform ios --max-workers 2 --output-dir /tmp/zubapp-export
```

Тесты проверяют рейтинг, фильтрацию и расчёт динамики. Экспорт проверяет сборку JavaScript
для обеих платформ; он не заменяет нативную сборку и проверку интерфейса на устройствах.
